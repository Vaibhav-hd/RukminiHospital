## Common Issues & Solutions

### Form Not Sending
- [ ] Verify email address in form action
- [ ] Check FormSubmit.co service status
- [ ] Try from different device/browser
- [ ] Check spam folder for test emails

### Images Not Loading
- [ ] Verify image files are in root folder
- [ ] Check file names match exactly
- [ ] Verify image file size
- [ ] Check file format (PNG/JPG)
- [ ] Try clearing browser cache

### Site Not Loading
- [ ] Clear browser cache
- [ ] Try different browser
- [ ] Check GitHub Pages status
- [ ] Verify repository is public
- [ ] Wait for deployment (up to 10 minutes)

### Mobile Menu Not Working
- [ ] Clear browser cache
- [ ] Try different mobile browser
- [ ] Check JavaScript errors in console
- [ ] Try landscape and portrait modes

### Styling Issues
- [ ] Hard refresh browser (Ctrl+Shift+R)
- [ ] Clear browser cache completely
- [ ] Try private/incognito mode
- [ ] Check all CSS is loaded
